# Déjà fait — choix de design par site

Règle : un nouveau site ne doit pas partager plus de 2 choix avec un site déjà listé.

## Garnier Cycles — atelier de vélos sur mesure (démo, novembre 2026)
| Axe | Choix |
|---|---|
| Hero | Produit isolé : vélo de profil en dessin technique au trait, centré ; nom monumental en bas sur toute la largeur |
| Grille | Bento (tuiles à filet, tailles variées) + tableau numéroté pour le procédé |
| Typo | Sofia Sans Extra Condensed 850 (titres, capitales) + Sofia Sans Semi Condensed (texte), chiffres tabulaires, pas de mono |
| Couleur | Aplats pleine page qui alternent : vert usine #0F4A35, jaune sécurité #F2D20A, noir bleuté #0D1117, rouge minium #C2331A ; texte #ECEFEA |
| Densité | Aérée (sections de 96 à 168 px) |
| Mouvement | Mécanique et sec : `power3.inOut`, `steps()`, snap à crans, aucun rebond |
| Mécaniques | Vue éclatée épinglée au scroll (6 pièces, 4 étapes verticales sur mobile) + compteurs à crans |
| Concept | « Planches » techniques numérotées 00–11, nomenclature, cotes jaunes |
| Références Inspo | savvycal.com, frerejones.com, hardwareoperations.com (+ eduardbodak.com, turnoev.com consultées) |
